02 / CORE METHODOLOGY ARCHITECTURAL DISCIPLINE
01. GROUNDING

Every quote exists.

Every finding must quote the exact page text. If the evidence quote cannot be verified in the DOM, it is strictly rejected.

02. ABSENCE ≠ LIE

Evidence gaps.

Missing evidence is classified as NOT_FOUND, never as a contradiction. Absence is an evidence gap, not proven falsehood.

03. HIERARCHY

Heuristic DOM zones.

Preserves DOM order and headings. Distinguishes prominent Hero promises from buried disclaimers hidden in footer footnotes.

04. ANTI-MASKING

Critical flags.

High average scores never conceal material legal or pricing contradictions. Severe mismatches raise an unmissable red banner.
